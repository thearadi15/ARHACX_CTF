# Linux Privilege Escalation

Focuses on escalating privileges from a low-privileged Linux user.

## Topics Covered
- SUID/GUID binaries
- PATH hijacking
- Cron jobs
- Capabilities abuse
- Misconfigured sudo
- Kernel exploits (rare)

## Skills Tested
- Linux internals
- Enumeration
- Misconfiguration discovery

## Challenge Style
- Local shell access provided
- Realistic server setups
- Enumeration-heavy
