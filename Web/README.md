# Web Exploitation

This category focuses on identifying and exploiting vulnerabilities in web applications.

## Topics Covered
- SQL Injection (Classic, Blind, Time-based)
- Cross-Site Scripting (XSS)
- Server-Side Template Injection (SSTI)
- Authentication & Authorization Bypass
- Request Smuggling
- CSRF & CORS Misconfigurations
- Logic Flaws & Race Conditions
- File Upload & Deserialization

## Skills Tested
- HTTP protocol understanding
- Web app logic analysis
- Payload crafting
- Burp Suite proficiency

## Challenge Style
- Realistic web apps
- Black-box & white-box
- No client-side flag validation

## Difficulty Levels
- Easy: Input validation flaws
- Medium: Logic & auth bypass
- Hard: Chained vulnerabilities
