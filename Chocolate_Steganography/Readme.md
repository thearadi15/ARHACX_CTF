## Steganography
Discover hidden data within files by analyzing how information can be concealed beyond normal visibility.

# Topics Covered
• Image steganography  
• Multi-layer hiding techniques  
• QR reconstruction  
• Bit-plane manipulation  
• XOR and visual obfuscation  
• Encrypted payload extraction  

# Skills Tested
• File format internals (PNG, JPEG)  
• LSB and non-LSB bit analysis  
• Image processing and reconstruction  
• Cryptography integration  
• Tool-assisted forensics (zsteg, stegsolve, custom scripts)  
• Logical reasoning and pattern correction  

# Challenge Style
• Multi-file dependency  
• Decoy-based misdirection  
• Reconstruction puzzle  
• Crypto + Stego combined  
• Finals-level trick-based design  
• Requires both automation and manual analysis
